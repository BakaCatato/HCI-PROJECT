# Responsive Design Fix Plan

## Breakpoints
- Mobile:  ≤ 480px
- Tablet:  481px – 768px
- Laptop:  769px – 1024px
- Desktop: 1025px+

## login.css fixes
1. Brand icon image sizing at all breakpoints
2. Login split layout: side-by-side (≥769px), single column stacked (≤768px)
3. Brand panel text/padding adjustments per breakpoint
4. Loader screen sizing
5. Login card max-width and padding at each breakpoint

## style.css fixes
1. Fixed buttons (cart, bag, profile) positioning/sizing at all breakpoints
2. Guitar grid: 3-col desktop, 2-col tablet/laptop, 1-col mobile
3. Guitar card fixed px dimensions → fluid/auto
4. Header h1 and p font scaling
5. Side panel max-width on mobile (full width)
6. Buy-now modal padding on mobile
7. About section padding/font
8. Search bar and filter buttons layout on mobile
9. Theme toggle overlap avoidance on mobile
