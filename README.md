# GnC Guitar Shop (Gitara ni Cata) 🎸

A web-based e-commerce platform specializing in musical instruments, particularly guitars. This project was developed as a Human-Computer Interaction (HCI) documentation project, aiming to provide a streamlined shopping experience.

## 📖 About the Project
The GnC Guitars online shop enables customers to browse, select, and purchase guitars with a simple checkout process. It focuses on essential e-commerce functionalities, making the shopping experience accessible to users in the Philippine market.

📅 Project Timeline: Initially presented on **March 13, 2025**, and is continuously being polished and updated by the lead developer up to the present.

## 🛠️ Technologies Used
The user interface was built using standard web technologies:
• HTML: Provides the core structure and layout of the webpage.
• CSS: Controls the design, appearance, button styles, and interactive hover effects.
• JavaScript: Adds client-side interactivity, such as detecting click events and updating the cart.
