# GnC Guitar Shop (Gitara ni Cata) 🎸

[cite_start]A web-based e-commerce platform specializing in musical instruments, particularly guitars[cite: 20]. [cite_start]This project was developed as a Human-Computer Interaction (HCI) documentation project, aiming to provide a streamlined shopping experience with a focus on different guitar types at various price points[cite: 3, 21].

## 📖 About the Project
[cite_start]The GnC Guitars online shop enables customers to browse, select, and purchase guitars with a simple checkout process[cite: 22]. [cite_start]It focuses on essential e-commerce functionalities, making the shopping experience accessible to users in the Philippine market[cite: 129, 130]. 

### ✨ Key Features
* [cite_start]**Product Catalog:** Displays various guitar models with images, names, and prices ranging from ₱3,999 to ₱26,900[cite: 46, 66].
* [cite_start]**Selection Interface:** Utilizes a radio button selection system for choosing desired products[cite: 47].
* [cite_start]**Shopping Cart:** Tracks selected items dynamically[cite: 49].
* [cite_start]**Checkout & Confirmation:** Features a checkout form and provides purchase verification with delivery information[cite: 51, 95].

## 🛠️ Technologies Used
The user interface was built using standard web technologies:
* [cite_start]**HTML:** Provides the core structure and layout of the webpage[cite: 25, 26].
* [cite_start]**CSS:** Controls the design, appearance, button styles, and interactive hover effects[cite: 30, 31, 33].
* [cite_start]**JavaScript:** Adds client-side interactivity, such as detecting click events and updating the cart[cite: 36, 37, 39].
